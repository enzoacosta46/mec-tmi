# Laboratorio 2 - Tecnologías de Microprocesamiento

## Microcontrolador
ATmega328P

## Lenguaje
Assembler AVR

## Contenidos principales
- GPIO
- Stack Pointer
- Direccionamiento de memoria
- Temporizadores y contadores
- Interrupciones
- USART / UART
- Look-Up Tables
- Máquinas de estado

## Problemas
- Problema A: Matriz de LEDs con UART
- Problema B: DAC R-2R con LUT
- Problema C: Plotter
- Problema D: Comunicación USART-UART
- Problema E: Automatización de puerta de garaje
